# DnD Party Tracker

Трекер персонажей и кампаний D&D для партии: листы персонажей, кубы, карты локаций
и переписка с гейммастером — в браузере, с телефона, в реальном времени.

**Сайт:** https://yevhop-pixel.github.io/dnd-party-tracker/

## Возможности

- **Лист персонажа** — статы, ХП, золото, черты, инвентарь, экипировка по слотам,
  NPC, квесты, зелья, расходники, заметки. Автосохранение в облако.
- **Кампании** — ГМ создаёт кампанию и раздаёт код; игроки входят по коду.
- **Гейммастер** видит листы всех игроков (только чтение), управляет картами
  локаций, пишет игрокам лично и объявлениями.
- **Кубы** — d4…d100, нотация `2d6+3`, преимущество/помеха, тайные броски;
  общая лента бросков кампании в реальном времени; честный рандом
  (`crypto.getRandomValues`).
- **Карты** — ГМ загружает картинки локаций и показывает нужную; игроки
  приближают и двигают карту (Leaflet).
- **Сохранки** — облако (Supabase) + экспорт/импорт JSON-файлом,
  совместимым с Android-версией приложения.

## Структура

| Папка | Что это |
|---|---|
| `web/` | Веб-клиент: React + TypeScript + Vite |
| `supabase/schema.sql` | Схема Postgres: таблицы, RLS-политики, RPC, realtime, storage |
| `android/` | Исходная Android-версия (Kotlin + Compose, локальная, однопользовательская) |

## Запуск локально

```bash
cd web
npm install
cp .env.example .env   # вписать URL и publishable-ключ своего проекта Supabase
npm run dev
```

Бэкенд — [Supabase](https://supabase.com): создать проект, выполнить
`supabase/schema.sql` в SQL Editor, отключить Confirm email в Auth → Sign In/Providers.

Деплой — GitHub Actions → GitHub Pages, автоматически при пуше в `main`
(см. `.github/workflows/deploy-web.yml`).

## Безопасность

Клиент ходит в Supabase напрямую с publishable-ключом; ключ публичен по
определению. Всё разграничение прав — Row Level Security в `schema.sql`:
игрок видит и правит только своё, ГМ читает листы своей кампании,
вступление в кампанию — только через RPC с проверкой кода.
